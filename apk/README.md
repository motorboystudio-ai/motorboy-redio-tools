# 📱 MotorBoy Tech Android APK (Build สำเร็จรูป)

โฟลเดอร์นี้บรรจุไฟล์ติดตั้ง APK ที่ทำการคอมไพล์สำเร็จรูปจากซอร์สโค้ดเวอร์ชันล่าสุด:

### 📦 รายการไฟล์ APK:
- `MotorBoyTech-latest-debug.apk` (72 MB)
- `app-debug.apk` (72 MB)
- `SHA256SUMS.txt` (สำหรับตรวจสอบความถูกต้องของไฟล์)

### 📲 วิธีติดตั้งบนมือถือ Android:
1. ดาวน์โหลดไฟล์ `.apk` ลงในมือถือ Android ของคุณ
2. เปิดไฟล์ `.apk` เพื่อเริ่มการติดตั้ง
3. หากระบบถาม ให้กดอนุญาต **"ติดตั้งแอปจากแหล่งที่ไม่รู้จัก" (Install from Unknown Sources)**
4. กด **ติดตั้ง (Install)** แล้วเปิดใช้งานแอปได้ทันที!
